# البوت الدراسي

بوت Telegram عربي للمعسكرات المجانية، Sticky Notes، وإدارة الجروبات.

## الإعداد على Railway

1. ارفع هذا المجلد إلى مستودع GitHub جديد.
2. أنشئ مشروعاً في Railway، ثم أضف خدمة **PostgreSQL**.
3. أضف خدمة من مستودع GitHub، وضع متغيرات البيئة التالية:
   - `BOT_TOKEN`: التوكن من BotFather.
   - `DATABASE_URL`: استخدم متغير قاعدة البيانات الذي يوفره Railway.
   - `OWNER_TELEGRAM_ID`: رقم حسابك الرقمي في Telegram.
4. اجعل أمر البدء: `npm run start`، وسيبني Railway المشروع تلقائياً عبر `npm run build`.
5. أضف البوت إلى جروب كمشرف، مع صلاحيات حذف الرسائل والحظر/التقييد وتثبيت الرسائل.

## ما توفره النسخة الأولى

- واجهة عربية في الخاص.
- حفظ وعرض ملاحظات Sticky Notes.
- عرض المعسكرات المنشورة في قاعدة البيانات.
- حذف الروابط من الجروبات وتسجيل العملية.

## تنبيه أمني

لا تضع `BOT_TOKEN` في أي ملف GitHub أو رسالة عامة. ضعه فقط في متغيرات Railway.
